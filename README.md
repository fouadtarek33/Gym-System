# 🏋️ Gym Membership System

A simple Gym Membership Management System built with **Python** using Object-Oriented Programming (OOP).

This project allows gym staff to manage members through a simple command-line interface (CLI).

---

## ✨ Features

- ➕ Add a new member
- 👥 Display all registered members
- 🔍 Search members by:
  - Membership ID
  - First Name
  - Membership Status (Active / Inactive)
- 🚪 Exit the program

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Dictionary for in-memory data storage

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Gym-Membership-System.git
```

2. Open the project folder:

```bash
cd Gym-Membership-System
```

3. Run the program:

```bash
python main.py
```

## 📌 Notes

- All data is stored temporarily in memory using a Python dictionary.
- Data will be lost after closing the program.
- No external libraries are required.
